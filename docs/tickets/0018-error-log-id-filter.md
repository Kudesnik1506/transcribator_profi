# 18 — Фильтр по ID Записи в логах ошибок требует точного ID, а UI показывает усечённый

GitHub: https://github.com/Kudesnik1506/transcribator_profi/issues/18
Label: `bug`

## What's wrong

На `/admin/errors` каждая запись лога показывает усечённый ID («Запись
5b3c165a»), но поле фильтра «ID Записи» ищет по точному равенству —
ввод усечённого ID из интерфейса ничего не находит («Логов не
найдено»). Работает только полный UUID, которого на экране нет — его
приходится добывать переходом по ссылке в запись.

## Acceptance criteria

- [ ] Фильтр находит записи по префиксу ID (совпадает с тем, что видно
      в UI)
- [ ] Существующее поведение точного совпадения по-прежнему работает
      (не regression для полного ID)

## Найдено

Живой браузерный e2e-прогон (Playwright MCP), 2026-08-06.
