## What to build

Пользователь задаёт вопросы по содержанию Записи и получает ответы, построенные только по её Транскрипту. История сохраняется и доступна при возврате.

Проверка на реальность: должны работать ровно те вопросы, что заказчик привёл примерами в ТЗ — «о чём говорилось в начале», «какие задачи были поставлены», «что сказали про бюджет», «перечисли всех упомянутых людей».

## Acceptance criteria

- [ ] Весь Транскрипт уходит в контекст каждого запроса, вместе с историей Диалога
- [ ] Ответы строятся только по Транскрипту; на вопрос вне записи модель это говорит, а не выдумывает
- [ ] Все четыре примера вопросов из ТЗ дают осмысленные ответы на реальной трёхчасовой записи
- [ ] История Диалога сохраняется и восстанавливается
- [ ] Ответ стримится, а не появляется через полминуты молчания
- [ ] Транскрипт, не влезающий в контекст модели, обрабатывается предсказуемо и с понятным сообщением
