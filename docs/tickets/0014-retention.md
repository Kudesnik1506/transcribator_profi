## What to build

Данные не копятся вечно. Исходное медиа живёт 30 дней, текстовые артефакты — 180. Разные сроки не прихоть: полгода хранения видео дают терабайты и заметный счёт, а текст стоит копейки.

## Acceptance criteria

- [ ] Ночная джоба удаляет медиа старше `MEDIA_RETENTION_DAYS`, оставляя Транскрипт, Сводку и Диалог
- [ ] Ночная джоба удаляет Запись целиком старше `DATA_RETENTION_DAYS`, включая объекты в S3
- [ ] Оба срока — параметры конфига, меняются без правки кода
- [ ] У Записи проставляется `media_deleted_at`, интерфейс это учитывает
- [ ] Прогон на подкрученных датах даёт ожидаемый результат и логируется
- [ ] Повторный запуск джобы безопасен
