## What to build

Заказчик разворачивает приложение у себя по README и дальше расширяет его сам. Это не финальная уборка, а пункт приёмки: «инструкция по запуску» и «хостинг сайта» стоят в ТЗ прямым текстом.

## Acceptance criteria

- [ ] `docker-compose.yml` для прода с TLS
- [ ] `.env.example` со всеми ключами и комментарием к каждому
- [ ] README описывает получение каждого ключа по шагам: S3, SpeechKit, AI Gateway, SMTP, Telegram
- [ ] README объясняет смену модели LLM и переключение режима ASR
- [ ] Описан бэкап и восстановление базы
- [ ] Развёртывание с нуля на чистой машине проходит по README без вопросов к автору
- [ ] Отладка на реальных трёхчасовых записях: оба режима, сбой Куска, обрыв загрузки
