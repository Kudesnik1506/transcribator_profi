## What to build

На странице результата играет исходная запись. Клик по абзацу перематывает на этот момент, а при воспроизведении текущий абзац подсвечивается сам.

Ограничение по замыслу: плеер работает, пока жив исходный медиафайл — 30 дней по решению D6. После этого остаётся текст.

## Acceptance criteria

- [ ] Плеер играет исходный файл из S3 по временной ссылке
- [ ] Клик по абзацу перематывает на его таймкод
- [ ] Текущий абзац подсвечен и остаётся в поле зрения при прокрутке
- [ ] Работает и для видео, и для аудио
- [ ] Если медиа уже удалено по ретеншну — вместо плеера понятное объяснение, текст доступен
