## What to build

Трёхчасовая Запись обрабатывается устойчиво: аудио режется на Куски, каждый распознаётся отдельно, сбой одного не убивает работу целиком. Пользователь видит, на каком этапе Запись и сколько процентов готово.

## Acceptance criteria

- [ ] Аудио режется на Куски по 10–15 минут, границы и смещения сохраняются
- [ ] Каждый Кусок распознаётся отдельной задачей с ретраем 3 раза и нарастающей паузой
- [ ] Таймкоды Сегментов абсолютные — смещение Куска прибавляется при сохранении
- [ ] Статусы `extracting → transcribing → summarizing → done`, плюс `partial` и `failed`
- [ ] Процент готовности считается по завершённым Кускам и виден пользователю
- [ ] Если часть Кусков не поднялась после ретраев — статус «Частично обработана», сохранённое доступно
- [ ] Есть повтор неудавшихся Кусков без переобработки успешных
- [ ] Ошибки пишутся в `error_logs` с контекстом
