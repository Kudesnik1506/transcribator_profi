## What to build

Пользователь загружает файл на 2 ГБ, видит честный прогресс, и если сеть оборвалась на середине — загрузка продолжается с места обрыва, а не начинается заново.

## Acceptance criteria

- [ ] Загрузка идёт частями через S3 multipart по пресайн-ссылкам
- [ ] Прогресс-бар отражает реально отправленные части, а не время
- [ ] Обрыв сети на 60 % не теряет уже загруженное
- [ ] Файл больше допустимого размера отклоняется до начала загрузки
- [ ] Незавершённые загрузки не оставляют мусор в S3
