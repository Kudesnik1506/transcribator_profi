# 17 — Неверное склонение «N совпадений» в поиске по транскрипту

GitHub: https://github.com/Kudesnik1506/transcribator_profi/issues/17
Label: `bug`

## What's wrong

`PlayerTranscript.tsx` всегда выводит `${matchCount} совпадений`, без
учёта числа. По-русски:
- 1 → «совпадение»
- 2–4 → «совпадения»
- 5+ → «совпадений» (кроме 11–14 → тоже «совпадений»)

Сейчас при одном совпадении показывается «1 совпадений».

## Acceptance criteria

- [ ] Число совпадений склоняется по стандартным правилам русского
      языка
- [ ] Покрыто тестом на границы (1, 2, 5, 11, 21)
