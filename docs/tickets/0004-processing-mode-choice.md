## What to build

При загрузке пользователь выбирает, обработать Запись сейчас или в фоне подешевле. Отложенный тариф SpeechKit вчетверо дешевле обычного при задержке до суток — решение о размене отдано тому, кто платит.

## Acceptance criteria

- [ ] На экране загрузки выбор из двух режимов с честным описанием задержки
- [ ] Дефолт — фоновый режим
- [ ] Режим сохраняется у Записи и виден в истории
- [ ] Оба режима дают идентичный по структуре Транскрипт
- [ ] Смена режима по умолчанию — параметр конфига, а не правка кода
