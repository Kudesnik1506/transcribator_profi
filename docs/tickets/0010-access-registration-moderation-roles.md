## What to build

Человек регистрируется сам, но работать может только после того, как Администратор его одобрит. Открытая регистрация недопустима: каждый Пользователь тратит деньги заказчика на распознавание и грузит на его сервер произвольный контент.

## Acceptance criteria

- [ ] Регистрация по email и паролю
- [ ] Новый Пользователь получает статус `pending` и видит экран «ожидает одобрения»
- [ ] Неодобренный Пользователь не может загружать Записи и не видит чужих
- [ ] Роли `user` и `admin`; первый Администратор заводится при развёртывании
- [ ] Заблокированный Пользователь теряет доступ, но его Записи сохраняются
- [ ] Пароли хранятся хешированными, сессии истекают
