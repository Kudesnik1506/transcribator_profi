## What to build

Пользователь ищет слово по всей Записи, а не по видимой части страницы, и переходит к найденному месту.

## Acceptance criteria

- [ ] Поиск идёт на сервере через полнотекстовый индекс PostgreSQL, конфигурация `russian`
- [ ] Работают словоформы: «бюджету» находит «бюджет»
- [ ] Совпадения подсвечены, показано их количество
- [ ] Переход к совпадению прокручивает текст и ставит плеер на нужный момент
- [ ] Поиск по трёхчасовой Записи отвечает без заметной задержки
