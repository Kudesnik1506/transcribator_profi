## What to build

Администратор управляет доступом, видит все Записи, удаляет ненужные и читает логи ошибок. Четыре страницы поверх уже существующих запросов.

## Acceptance criteria

- [ ] Список Пользователей с одобрением и блокировкой
- [ ] Список всех Записей с фильтром по Пользователю и статусу
- [ ] Удаление Записи убирает и объекты в S3, а не только строки в БД
- [ ] Логи ошибок с фильтром по уровню и Записи
- [ ] Обычный Пользователь на страницы админки не попадает — ни по ссылке, ни через API
