## What to build

Пользователь может загрузить не больше трёх Записей за календарные сутки. Это второй предохранитель после модерации: он ограничивает расход, даже если уже одобренный Пользователь начнёт лить лишнее.

## Acceptance criteria

- [ ] Лимит считается по календарным суткам МСК на Пользователя
- [ ] Четвёртая попытка отклоняется с сообщением, когда квота обновится
- [ ] Величина квоты — параметр конфига
- [ ] Неудавшиеся Записи квоту не съедают
- [ ] Администратор квотой не ограничен
