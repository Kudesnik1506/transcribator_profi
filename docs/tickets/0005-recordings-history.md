## What to build

Пользователь видит список своих Записей и может открыть любую. По каждой видно имя файла, дату, статус и прогресс.

## Acceptance criteria

- [ ] Список показывает имя исходного файла, дату, статус и процент
- [ ] Записи в работе обновляют статус без перезагрузки страницы
- [ ] Переход на страницу результата из списка
- [ ] Пользователь видит только свои Записи
- [ ] Пустой список объясняет, что делать дальше
