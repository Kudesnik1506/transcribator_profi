## What to build

Пользователь узнаёт, что Запись готова, не возвращаясь на сайт. В фоновом режиме ожидание доходит до суток — статуса в интерфейсе для этого недостаточно, человек просто не вернётся.

## Acceptance criteria

- [ ] Письмо при переходе Записи в `done`, `partial` или `failed`
- [ ] В письме имя файла, итог и прямая ссылка на страницу результата
- [ ] Привязка Telegram по одноразовому коду, дублирование уведомления в бот
- [ ] Telegram опционален — без привязки всё работает
- [ ] Недоступность SMTP или Telegram не роняет обработку, а пишется в логи ошибок
- [ ] Уведомление отправляется один раз, повторы при ретраях исключены
