# 01 — Сквозной скелет: файл → Транскрипт → Сводка

GitHub: https://github.com/Kudesnik1506/transcribator_profi/issues/1
Label: `ready-for-agent`

## Blocked by

None — can start immediately

## What to build

Пользователь загружает короткий аудиофайл и через несколько минут видит страницу с полным текстом и Сводкой. Одна тонкая вертикаль насквозь — без авторизации, без дизайна, без обработки ошибок сверх минимума.

Это тикет-трассер: его задача — вскрыть все интеграционные сюрпризы SpeechKit, ffmpeg, S3 и AI Gateway на первой неделе, а не на последней.

## Acceptance criteria

- [ ] `docker compose up` поднимает api, worker, postgres, redis и web на чистой машине
- [ ] Файл уходит в Timeweb S3 по пресайн-ссылке, минуя бэкенд
- [ ] Воркер извлекает моно OggOpus через ffmpeg и отправляет в Яндекс SpeechKit телом запроса
- [ ] Сегменты сохраняются в БД с абсолютными таймкодами от начала Записи
- [ ] Сводка генерируется через Timeweb AI Gateway и сохраняется
- [ ] Страница результата показывает Транскрипт и Сводку
- [ ] Ключи читаются из `.env`, в репозиторий не попадают
