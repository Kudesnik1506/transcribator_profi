## What to build

Пользователь забирает результат из системы в привычном формате.

## Acceptance criteria

- [ ] Выгрузка в `.txt` — сплошной текст без разметки
- [ ] Выгрузка в `.srt` с таймкодами
- [ ] Выгрузка в `.docx`
- [ ] `.srt` открывается плеером и попадает в такт со звуком
- [ ] `.docx` открывается в Word без предупреждений о повреждении
- [ ] Имя выгружаемого файла построено от имени исходного
