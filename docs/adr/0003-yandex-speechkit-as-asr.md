# Яндекс SpeechKit как движок распознавания, за интерфейсом провайдера

Распознавание идёт через Яндекс SpeechKit в асинхронном режиме, но вызовы спрятаны за интерфейсом ASR-провайдера, чтобы движок можно было заменить без переписывания приложения.

Выбор **вынужденный, а не предпочтительный** — и именно поэтому записан. Заказчик оформлен как физическое лицо, и на 2026-08-05 это отсекает почти весь рынок: Sber SaluteSpeech закрыт для новых клиентов с 15.07.2026, T-Bank VoiceKit работает только с ИП и юрлицами по договору, зарубежные API недоступны из РФ (см. [ADR-0001](./0001-hosting-in-russia.md)). SpeechKit остаётся единственным облачным ASR с пословными таймкодами, доступным физлицу с оплатой картой или через СБП.

## Considered Options

**Whisper large-v3 self-hosted** — отклонён. Бесплатность лицензии не компенсирует качество: средний WER на русском 16–21 % против 8–9 % у GigaAM по бенчмарку из 10–11 датасетов, а на разговорной речи (Golos Crowd) разрыв доходит до 14.7–19.0 против 2.2–2.8. Плохой транскрипт отравляет весь конвейер вниз по течению — сводка, чат и поиск работают по испорченному тексту. **Если проект когда-либо уйдёт в self-hosted, целиться нужно в GigaAM v3 (лицензия MIT), а не в Whisper.** Эту строку стоит перечитать любому, кто в будущем предложит «просто взять Whisper, он бесплатный».

**Self-hosted GigaAM v3 сразу** — отложен, не отвергнут. Требует GPU, а прайс на GPU у Timeweb Cloud непубличный: только форма заявки и авансовый платёж от 5 000 ₽. Решение отложено до получения коммерческого предложения; переключение возможно на этапе 2 вместе с диаризацией, которой GPU нужен в любом случае.

**Timeweb AI Gateway (`gpt-4o-mini-transcribe`)** — отклонён: поддержка таймкодов не подтверждена, а таймкоды требует ТЗ.

## Consequences

- Абстракция провайдера — не архитектурное украшение, а прямая страховка от вынужденности выбора. Её нельзя «упростить»
- SpeechKit не принимает видео — извлечение аудиодорожки через ffmpeg обязательно всегда
- Диаризация SpeechKit ограничена двумя дикторами и только моно, то есть для совещаний непригодна (отсюда отказ от диаризации в MVP)
- Два тарифа отличаются вчетверо (36,36 ₽/час против 9,14 ₽/час) при разнице в задержке от получаса до суток, поэтому выбор режима вынесен пользователю в интерфейс
