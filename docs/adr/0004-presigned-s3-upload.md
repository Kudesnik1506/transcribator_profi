# Загрузка напрямую в S3 по пресайн-ссылке

Браузер грузит файл напрямую в Timeweb S3 частями по пресайн-ссылкам, минуя бэкенд. Бэкенд только выдаёт ссылки и принимает уведомление о завершении.

Причина в размере: файлы до 2 ГБ. Обычный `multipart/form-data` на таком объёме рвётся от таймаутов nginx и от любого обрыва сети, и пользователь теряет десятки минут загрузки целиком. Прямая загрузка частями даёт честный прогресс-бар, докачку с места обрыва и снимает с сервера весь входящий трафик.

Это решение попутно закрыло вопрос выбора хранилища: S3 стал следствием, а не отдельным решением.

## Consequences

- Дешёво сделать сразу и дорого прикручивать потом — переезд с загрузки через бэкенд означал бы переписывание всего слоя загрузки и отдачи
- Требование ТЗ «отображение прогресса загрузки» выполняется по-настоящему, а не индикатором «идёт отправка»
- Бэкенд не масштабируется под трафик, потому что трафика через него нет
