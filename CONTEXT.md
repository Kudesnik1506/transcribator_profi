# Транскрибатор

Веб-приложение для транскрибации аудио и видео: пользователь загружает файл, система распознаёт речь с таймкодами, генерирует краткую сводку и позволяет задавать вопросы по содержанию.

## Language

**Запись**:
То, что загрузил пользователь, вместе с исходным медиафайлом. Единица работы системы — всё остальное принадлежит Записи.
_Avoid_: файл, обработка, материал, задача

**Транскрипт**:
Полный текст Записи с таймкодами. У Записи ровно один Транскрипт.
_Avoid_: транскрипция, расшифровка, текст

**Сегмент**:
Единица Транскрипта — отрезок речи с временем начала, временем конца, текстом и говорящим. Таймкоды абсолютные, от начала Записи.
_Avoid_: фраза, реплика, строка

**Кусок**:
Фрагмент аудио на 10–15 минут — единица распознавания и повторной попытки. Внутреннее понятие конвейера, пользователю не показывается.
_Avoid_: чанк, часть, фрагмент

**Сводка**:
Краткое содержание Транскрипта: 5–15 пунктов с тезисами, темами, выводами и списком действий. У Записи ровно одна Сводка.
_Avoid_: саммари, конспект, резюме

**Диалог**:
История вопросов пользователя и ответов системы по одной Записи. Ответы строятся только по Транскрипту этой Записи.
_Avoid_: чат, сессия, переписка

**Обработка**:
Не сущность, а **статус Записи** в конвейере. В истории пользователь видит список Записей, а не список обработок.
_Avoid_: задание, джоба

**Пользователь**:
Человек с учётной записью. Регистрируется сам, работать может только после одобрения Администратором.
_Avoid_: клиент, юзер, аккаунт

**Администратор**:
Пользователь с правом одобрять регистрации, видеть Записи всех Пользователей, удалять их и читать логи ошибок.
_Avoid_: модератор, владелец

**Квота**:
Ограничение на число Записей, которые Пользователь может загрузить за календарные сутки.
_Avoid_: лимит, ограничение
